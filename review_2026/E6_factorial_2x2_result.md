## 1. 主效应 1：证据门（`PATCH_EVIDENCE_GATE_ENABLE` on/off）

| 指标 | 配对检验（c1 vs c3） |
|---|---|
| detection | 不一致 **4:3**、χ²=0.000、**p=1.0000** → **无效应** |
| repair(correct) | 不一致 2:2、p=1.0000 → **无效应** |
| **落盘补丁数** | **27 → 45（+18 行）** |
| **correct 数** | **32 → 32（完全不变）** |

**🔴 关键结论：关掉证据门**没有**换来 correct 总量的提升，但**显著降低补丁精确率**。**

| 口径 | gate ON | gate OFF |
|---|---|---|
| 落盘补丁数 | 27 | **45** |
| 其中 correct | **25** | 32 |
| **落盘精确率** | **92.6%** | **71.1%** |
| 全任务 correct 总量 | 32/46 | **32/46（不变）** |

- 多落盘的 18 行中，**correct 增量为 7 行、错误 11–13 行**（精确核算：
  OFF 侧 45 落盘 / 32 correct → 13 错误；ON 侧 27 落盘 / 25 correct → 2 错误）；
- **全任务 correct 总量 32 → 32 完全不变**；
- **detection 配对 4:3、p=1.0000 → 无效应**；**repair 配对 2:2、p=1.0000 → 无效应**；
- **因此证据门的真实作用是「提高落盘补丁的信噪比」（+21.5pp 精确率），
  而不是「损失修复能力」**。它以"回滚 18 行"为代价，把精确率从 71.1% 提到 92.6%，
  同时 correct 总量零损失——**这是一笔明显划算的交易**。
- ⚠️ **自我更正**：本节初稿写"多落盘的 18 行**全部**是错误补丁"，**该表述不准确**，
  实际 correct 增量为 7 行。已按上表精确口径更正。
- **本审查上一轮把证据门列为"最高 ROI 修复（+16.5pp repair）"的判断，经真实 A/B 证否**
  （correct 总量不变）；该 +16.5pp 源自对工件 `patch_correct` 字段的静态重放，
  未做真实 A/B。**证据门应视为"有效守门"**。

## 2. 主效应 2：逻辑通道（`SPEC_ORACLE_EXEC_ENABLE` off/on）— **在两个 gate 层上一致为负**

| 对照 | detection 配对 | 结论 |
|---|---|---|
| c1(off) vs c2(on)，gate 固定 ON | 不一致 **12:1**、χ²=7.692、**p=0.0055**（精确二项 **0.0034**） | **显著下降** |
| c3(off) vs c4(on)，gate 固定 OFF | 不一致 **9:2**、χ²=3.273、**p=0.0704**（精确二项 0.0654） | **同向，边际** |

**两层的方向一致（12:1 与 9:2），且效应量与首次 A/B（12:3）同向。**
pooled 三层：不一致对 33:6 → χ²≈19.2，**远低于 0.001**。

| 层 | detection |
|---|---|
| gate ON | 26/36 (72.2%) → **14/36 (38.9%)**，**−33.3pp** |
| gate OFF | 25/36 (69.4%) → **18/37 (48.6%)**，**−20.8pp** |

**机制（三臂一致）**：oracle 注入使 **over_red 显著升高**
（ON 层 17→31；OFF 层 20→28）。
即注入的 oracle 断言**在 gold fixed 上失败** → 门①判 `over_red` → 压低检出。

**repair 不受影响**（两层 p 均 ≈ 1.0）：oracle 只伤检出、不伤修复。

## 3. 交互效应

| | oracle OFF | oracle ON | Δ |
|---|---|---|---|
| gate ON | 26/36 | 14/36 | **−12** |
| gate OFF | 25/36 | 18/37 | **−7** |

oracle 的负效应在 gate ON 时**更大**（−12 vs −7），提示两者存在**负向交互**：
证据门已挡住一部分"坏补丁"，而 oracle 额外注入的过红又进一步抬高了 over_red
（gate ON: 17→31，+14；gate OFF: 20→28，+8）。
n 较小，**交互项不作强结论**，仅登记方向。

## 5. 口径限定（必须随数字引用）

1. **n=36/37，各对照不一致对 3–12**；gate 主效应为**零结果**（p=1.0），
   在 n≈36 下"无差异"只能作**等价性方向的弱证据**，不是"证明无效应"；
2. **oracle 主效应为 ITT 口径**（c2 19/46、c4 18/46 实际注入）；
3. 本批**关闭变异评分** → 无 mutation 指标；
4. 四臂 det_measured 分母 36/36/36/37 略有差异，配对检验已按**共同任务集**重算；
5. **未做聚类校正**（QuixBugs 任务间无模板簇，但可能共享缺陷族）；
6. gate ON 臂的 `patch_plausible` 语义是"写盘成功"，而 gate OFF 臂不会回滚，
   故"落盘数"差异是**门禁行为差异**而非"修复能力差异"——这正是本次要测的。
