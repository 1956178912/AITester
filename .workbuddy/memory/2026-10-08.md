## R4 约束粒度升级：函数级 → 行级（针对 A/B 空洞根因）
- 根因：首版 validate_edit_localization 用 AST 提取"函数定义行范围"判定锚点落点，完全忽略 loc 的 line_start/line_end（缺陷语句行）→ 单函数任务上"候选函数=整个被测代码"= 空洞约束（A/B 实测 localized_ratio 恒 1.0、repair 逐任务一致 8/50）。

## 重大发现 + 修复：QuixBugs repair=0 是测量层 bug（gold 测试 import 路径不匹配）
- 归因链：QuixBugs B 臂 20 个 plausible 补丁 → 9 个"弃权门未标记但 correct=0"盲区 → 用 gold 官方测试直跑 **9/9 全 PASS**（真正确修复）→ 复现 _compute_repair_rate 见 `ModuleNotFoundError: No module named 'node'`（rc=2 收集错误）。

- 修复：新增 `_quixbugs_support_root` + `_prepare_packaged_test_tree`（镜像包目录树：python_programs 包 + correct_python_programs 占位 + conftest + 从 AITESTER_QUIXBUGS_DATA 复制 node.py/load_testdata.py/json_testcases + 测试 prelude 注入 pytest.use_correct）；`_run_pytest_in_tmp` 检测 `python_programs` 走包分支，synthetic 单文件走历史分支（零回归）。

- 测试：新增 tests/test_m1_packaged_tests.py（7 项）；引用 _m1_metrics 的 6 个测试文件 84 passed 零回归；ruff 全绿。
