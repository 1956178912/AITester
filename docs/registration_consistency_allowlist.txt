# 分册清单豁免登记（判定面：docs/INDEX.md §3.5 与 docs/INDEX.en.md §3.5 的「在盘 → 清单」方向）。
#
# 语法（一行一条，`#` 之后是理由，无理由即红）：
#     <分册文件名>:<INDEX 文件相对路径>  # <为什么这份分册可以不进这张清单>
# 例：
#     STATE_CHANNEL_AUDIT_SURFACE_CB_2026-10-23.md:docs/INDEX.en.md  # 中文版独占，en 侧由 §3.5 的 (Chinese) 行覆盖
#
# 纪律（CA 轮同族）：豁免必须是**判定**，不是便利。以下四种都计红——
#   ① 无理由；② 指向不存在的分册（陈旧豁免——目录/文件改名后豁免不会自己失效，必须删）；
#   ③ 同一 `<分册, INDEX>` 组合重复登记；④ 格式不符（缺 `:` 分隔）。
# 豁免只作用于「盘 → 清单」这一方向：`check_doc_links.py` 仍判「清单 → 盘」（死链方向不可豁免）。
