## 0. 一句话结论

AC-1 修的是"算错的 p"；AD 轮把同一条缺陷类查完——**渲染层还有一处同款丢失**
（`{:.4f}` 把非零小量级印成 "0.0000"，精确值与精度丢失在账面上同形），
另有一处同族补集模式（`1.0 - _normal_cdf`）。两处都已修复（11 例回归锁 +
双修复变异验证）；四类模式的全仓普查逐点判定，同族其余点位均良性/一致，不动作。

## 1. AD-1：`_fmt_stat_num` 销毁量级（渲染层）

### 1.1 现象

`{:.4f}` 对 |v| < 5e-5 的非零值一律印 "0.0000"。AC-1 修复前，主批
plain_llm_df vs plain_llm 的 p=5.890715e-26（χ²=111.00885 的精确值）与
下溢的 p=0.0 在报告里**同形**（都显示 "0.0000 (***)"）。也就是说：即使
p 值算对了，读者也无法从账面区分"精确算出的极小值"与"精度丢失"——
AC-1 之所以能藏到一轮独立复算才发现，渲染层是同谋。

### 1.2 修复与回归锁

- 修复（`experiments/statistical_analysis.py`）：非零且 |v| < 1e-4 →
  `{:.2e}`；精确 0.0 仍印 "0.0000"（零是合法统计值：χ²=0 / 无不一致对）；
  -0.0 保留符号（既有 `{:.4f}` 行为）；nan/inf 与正常量级渲染不变。
- 回归锁 `tests/test_ad_round_stat_display.py::TestStatNumMagnitudePreserved`：
  极小 p/q 渲染、中等量级 p 渲染、精确零、负小量级、正常量级不变、
  nan/inf、阈值边界（1e-4 上沿定点 / 9.99e-05 科学计数法）、
  **端到端**（主批 plain-df 经生产 `mcnemar_test` + `_fmt_stat_num`
  渲染出 "5.89e-26"——AC-1 可见性闭合）。
- 变异验证（独立验收员复核实测，见 §6）：pre-AD-1 实现 → **5 例转红**
  （极小 p / 中等量级 / 负小量级 / 阈值边界 / 端到端）；连 nan/inf 分支一并
  去掉的纯 `fmt.format(value)` → **6 例**；AD-2 语义回退（CDF + 调用点
  `2·(1−CDF)`）→ **2 例**；两修复合计 7 例，全部还原后转绿。**登记初稿把
  合计 7 记在 AD-1 单处，已更正**。
- 测试质量边界（如实登记）：11 例中 3 例（nan/inf、正常量级、精确零）是
  **保持性断言**（旧实现也绿，不承担"回退必红"）；AD-2 的
  `p_normal_approx` 显示域断言在完整语义回退下仍绿——旧补集与新 erfc 式在
  4dp 显示域内数学上不可区分，"接线"只能由"旧名 `_normal_cdf` 不存在"
  （导入/收集即失败）钉住，该边界不作更强主张。
- 历史产物不改写：canonical `statistical_report.md` 等既有报告保持原渲染
  （日期化勘误纪律）；改进对未来的重新生成生效。

## 2. AD-2：正态尾部补集模式（`emse_testlevel_detection`）

- 旧：`2.0 * (1.0 - _normal_cdf(max(z, 0.0)))`——`1.0 - cdf` 在 z ≳ 8.2 时
  因浮点精度静默变 0.0（与 AC-1 的 `1 - chi2.cdf` 同型）。
- 新：`_normal_sf(z) = 0.5 * math.erfc(z / math.sqrt(2.0))`。与 scipy
  `norm.sf` 相对误差 < 1e-12（实测 z ∈ [0,8] 各点相对误差 1.8e-16~1.3e-14，
  **仅 z=0 逐位相同**；登记初稿写"逐位一致"过度，已更正）；实测该式到
  **z=38.4666** 才下溢为 0.0（旧 `1−cdf` 首次恒 0 于 z=8.2658 ⇒ 覆盖整个
  可显示区间）。
- 该字段 `round(..., 4)` 显示且无数字消费者 ⇒ 可显示区间读数逐位不变，
  **改动消除的是模式本身**（判据：不为凑覆盖保留已知下溢通道）。
- 回归锁 3 例（scipy 对拍 / z=10 处旧模式坐实下溢而新函数精确 /
  wilcoxon `p_normal_approx` 显示域读数不变）；变异验证：回退补集 → 2 例转红。

## 3. 全仓普查：四类静默精度丢失模式逐点判定

| # | 模式 | 点位（证据） | 判定 |
|---|---|---|---|
| 1 | 补集 `1 − cdf` | `statistical_analysis.mcnemar_test`；`emse_testlevel_detection._normal_cdf` | **两处全处置**（AC-1 / AD-2） |
| 2 | 补集 `1 − prod` | `statistical_analysis._pass_at_k_value:1115-1118` | 良性：k ≤ n−c 时各因子 ∈ (0,1)，prod 下溢 ⇒ 真值即 1.0 到机器精度；k > n−c 已有恒 1.0 分支；`{:.4f}` 渲染不变 |
| 3 | 乘积 `p·(1−p)` | `emse_stats_report.py:161`、`pass_matched_sensitivity.py:77`（Wilson CI） | 良性：乘积非补集；p=1 时因子为精确 0（值域闭合） |
| 4 | 除法 `(po−pe)/(1−pe)` | `e7_adjudication.py:249`（Cohen's κ） | 良性：`p_e >= 1.0` 已有守卫返回 None；pe→1 时 κ 数学上确应发散 |
| 5 | `exp(log 差)` | `emse_quixbugs_specir_expand.py:102`、`emse_optimization.py:190`（BF10） | 良性：下溢到 0.0 是"证据支持 H0"的 intended 语义；上溢会响亮抛 OverflowError（非静默） |
| 6 | `inv_cdf(1−α/2)` | `emse_stats_report.py:128` | 良性：α 为常量 0.05，1−α/2=0.975 远离 1 |
| 7 | 浮点相等 `== 1.0` | `four_channel_recompute`、`pass_matched_sensitivity`、`emse_quixbugs_specir_expand`（协议 0/1 值消费者） | 一致习语：生产者 `_compute_detection_rate`（`_m1_metrics.py:722`）只返回字面量 1.0/0.0/None，归档值经 JSON 往返仍精确；无"计算值相等"点位 |
| 8 | 灾难性抵消 | `rag_ab_experiment._var`（两遍法）、`stvr_statistical_analysis`（stdlib `statistics.variance`） | 良性：两遍法 `sum((x−m)²)` 数值稳定；无 `sum(x²)−n·m²` 单遍式 |

**方法学注记**："良性"判定全部给证据（读生产者值域 / 读守卫 / 读渲染口径），
不凭模式名推断——AB 轮的真实语料重放正是"推理前提被工件否证"的先例。
