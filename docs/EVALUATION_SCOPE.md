# 评估声明范围表（Claim–Evidence Scope Table，EMSE 编辑/审稿人用）

- 最后更新：2026-10-15（EMSE 多轮优化批次；建立于第 1–11 步诊断与四路仓库审计之后）
- 性质：**内部可判性工件**，不替代论文；作用是让编辑与审稿人在 5 分钟内确认
  "每条对外声明有什么证据、属哪个口径、是否越界"。
- 纪律：本表只记录**可复算事实**（附工件路径）与**明确标注的推断**；
  凡证据不足者一律标 `未证实/未评估`，**不得**用叙述填补。表内不引入任何
  未经上述文档登记的数字。

## 0. 状态定义

| 状态 | 含义 |
|---|---|
| `supported` | 有可复算工件支持，且方向/量级按口径标签引用不会误读 |
| `partial` | 有支持证据，但样本量、构念或外部效度不足以支撑一般化 |
| `contradicted` | **本文档自己的数据与声明相反**（最关键的一类，必须改稿） |
| `not_evaluated` | 实验未执行或基础设施失败 → **既非阳性也非阴性** |
| `not_supported` | 设计不支持该结论（无论数据如何） |

## 2. 三指标的"不可分离性"（本文档最需要编辑理解的一点）

| 事实 | 工件 | 含义 |
|---|---|---|
| 三臂**条件** false-fix 均 100% | `PASS_MATCHED.md` §2 | 在本文设计中，"声明成功"与"假修复"几乎同义 → 边际 false-fix 的跨臂差异**只**反映成功声明率 |
| 成功声明率 54.79% / 87.74% / 2.68% | `PASS_MATCHED.md` §1（含 Wilson CI） | 该指标是被协议直接改变的行为指标，必须与 detection/repair 并列呈现，而非隐式分母 |
| 21 行 M10 第 0 轮死亡使 detection 分母为 240（≠261） | `statistical_report_3seed_pooled.md`；`tests/test_emse_optimization.py` 断言 | 引用任何比例时必须写明分母（261 / 240 / 143）与不可测口径（None 不进分母） |

## 3. 与 EMSE 五维标准的对应（供编辑初筛参考）

| EMSE 维度 | 本项目的可判性证据 | 当前判定 |
|---|---|---|
| Relevance | detection-first 协议、false-fix、benchmark 饱和三议题均落在 EMSE 2025–2026 活跃区 | 足够 |
| Significance | 真实可发表的增量在 C2/C5（对自身主指标的反证）与 C3/C7（稳健阴性 + 伪影治理），**不在**"更好的测试生成方法" | 需按此重构贡献定位 |
| Technical quality | 效应量 + CrI + BH-FDR + 聚类 DEFF 校正 + 缺失双界 + MDE（`emse_stats_report.md`）；**缺**人工/oracle 外校（E7 未执行，无 Kappa） | 达标但构念效度留 open |
| Scholarship | 与 EMSE 近期工作的逐条对话**尚缺**；外部证据并列呈现但未形成对话表；`docs/citation_allowlist.txt` 仍有 4 处待核验 | **最大缺口** |
| Presentation | 结构化摘要、五级 Open Science 自查、量纲标签纪律（`BASELINE.yaml caliber_labels`）、报告-工件对账门禁已具备；稿件本身尚不存在 | 需成稿 |
