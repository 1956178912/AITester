# 文档链接门禁（scripts/gates/check_doc_links.py）例外登记清单。
#
# 格式（每行一条，行尾必须给理由）：
#     <源文件相对仓库根路径>:<链接目标原文>  # 理由（为什么该链接是"真实例外"而非坏链）
#
# 口径：
#   - 命中本清单的链接记 [allow]（warning 级，不阻断 --strict），命中数计入统计；
#   - **每行必须写理由**（行内 ` # ` 之后）：无理由的豁免会被门禁判为 error。
#     豁免等于"人工已判定该链接可接受"，是有成本的承诺，不得无脑批量加入；
#   - `<链接目标原文>` = 文档里 `](...)` 括号内的原始字符串（含 `#anchor` 与
#     相对路径写法，逐字匹配；不解析为绝对路径）；
#   - 修复链接后应删除对应行，勿留死条目（死条目会让"清单 = 真实例外"的
#     假设失真，后续维护者据以判断时会得出错误结论）。
#
# 当前无条目：2026-10-17 WP-C 批次已把扫描面内的坏链全部修实（见
# docs/INDEX.md §4 的维护口径），因此无需登记任何例外。
# 历史上唯一一条坏链是 docs/troubleshooting.md 指向尚未创建的
# troubleshooting.en.md——该处已改为纯文本"English（待补，暂无对应文件）"，
# 未走 allowlist。
