# 复现环境四元组（N08，2026-10-30 冻结）

新批次复现声明必须钉死四元组，缺一 fail-closed、跨四元组不可混池：

- **seed**：显式值（如 `--seed 42`）；不传 LLM API——同 seed 只保证任务采样与执行顺序可复现；
- **模型**：别名 + `system_fingerprint`（响应头）双记录；别名解析到不同快照即视为不同模型（S29 漂移条款）；
- **温度**：测量批强制 `TEMPERATURE=0.0`；探索批除外并须披露；
- **数据集版本**：数据集名 + 子集 + 任务数 + 内容指纹（排序后 sha256——数据集文件随下载重生成，路径/行号不可靠）。

四元组缺任一分量即不可复现；服务端快照漂移按 E8/B2 轮披露口径（读数带快照标签）。
