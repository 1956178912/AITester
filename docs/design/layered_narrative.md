## 0. 一页结论（分层叙事地图）

EMSE 投稿的"规格优先 + 形式化规约"主张**必须按数据集分层**，三数据集
结论不可混述：

| 数据集 | 类型 | spec_compile_rate（新门） | detection 基线 | SpecExpr 增益 | 叙事定位 |
|---|---|---|---|---|---|
| QuixBugs（n=50） | 真实基准 | **0.7161**（旧门 0.6321） | ~63%（首轮即红 49/50） | **阳性趋势** δ=+14.29pp / p=0.125（n=35，标准口径） | 主张成立的**主证据**，须带功效限定语 |
| ULT（n=25） | 真实基准 | **0.5937**（旧门 0.5626） | 0/24（生成测试不产红） | 无 detection 判别力（零基线无 McNemar） | **变异强但缺陷盲**——mutation 维度主证据 |
| synthetic（n=174） | 合成模板 | **0.6397**（旧门 0.3102） | ~3%（无 flip 空间） | **阴性（信息性真阴性）** δ=−0.57pp / p=1.0 | **天花板反例**——证明增益需"差一步就检出"基数 |

**核心机制**（§6.8 勘误后定案）：SpecExpr 增益的**主机制=基线天花板**
（detection 基线决定 flip 空间），**非**"完整规格优先退化为近纯 NL"
（旧推断有误）。三数据集新门可编译率全部 ≥0.35，"逻辑驱动"可编译率
主张成立；旧门"数据集强分化"（0.63/0.56/0.31）系**度量假象**
（Planner 降级静默失败，§6.9 修门后消除）。

## 1. 分层结论 1：detection 基线天花板（§6.7 主机制）

**事实**：
- QuixBugs 干净口径 detection 基线 ~63%（首轮即红 49/50）→ 有 ~37%
  flip 空间（0→1 检出）；
- synthetic 干净口径 detection 基线 ~3%（6/174 vs 5/174）→ 几乎无
  flip 空间；
- ULT 生成测试 detection 0/24 → 零基线（MCNemar 无判别力）。

**推论**（设计敏感性，预注册 61a7e04）：synthetic 上 +12pp 效应
（QuixBugs 量级）预期不一致对 ≈25，实测仅 3 → **阴性非功效失败，
是信息性真阴性**（基线天花板所致，非 SpecExpr 无效）。

**论文措辞纪律**：SpecExpr 增益主张**必须带数据集限定语**
（"在有可观 detection 基线的数据集上"），不得笼统表述为
"SpecExpr 普遍有效"。

## 2. 分层结论 2：可编译率度量假象（§6.9 勘误）

**事实**（§6.9 DSL 度量门修复后三数据集新门校准）：
- 旧门口径"数据集强分化"（QuixBugs 0.63 / ULT 0.56 / synthetic 0.31）
  主因 = **Planner 降级时签名提取静默失败**（function_name 为空或
  字面量 "unknown" → 回退默认参数集 {r,x,a,b,y} → 参数名/result
  子句被误判 unknown_name——合成集 270 次拒绝主源）；
- 修门后新门口径：QuixBugs **0.7161**（+8.4pp）/ ULT **0.5937**
  （+3.1pp）/ synthetic **0.6397**（+33pp）——上修幅度 ∝ Planner
  降级率（synthetic 降级率最高 → 上修最大）；
- 同任务新抽样 expr 覆盖率不变（0.693→0.686 / 0.748→0.707），
  而 unknown_name 拒绝崩塌（129→35 / 141→53）→ 分化是**度量侧**
  假象，非 DSL 表达力问题。

**推论**：BASELINE 已统一为新门口径（旧值留注释供审计）。对外引用
spec_compile_rate **必须带数据集标签 + 门口径标签**（新门 vs 旧门）。

## 3. 分层结论 3：变异强但缺陷盲（ULT 维度洞察）

**事实**（M2 ULT Mut@k 收口，cosmic-ray 8.7.0 官方口径，零 LLM）：
- 生成测试·完整规格优先（specir 探针 25）：Mut@k = **0.928**
  （232/250）；
- 生成测试·纯 NL 规格优先（ult_lite46 46）：Mut@k = **0.9543**
  （439/460）；
- gold 官方测试（上界参照，探针 25）：Mut@k = **1.0**（250/250）；
- 同批 specir 生成测试 **detection = 0/24**（不在缺陷码上变红），
  却杀死 92.8% 的 fixed 变异体。

**机制**：测试断言的多是 buggy/fixed 上都成立的**不变量**
（规格后置性质）——对随机变异敏感（mutation 维度强），对种子缺陷
不敏感（F2P detection 维度盲）。

**论文定位**：这是"测试强度（变异维度）与缺陷检出（F2P 维度）
**可分离**"的直接证据——回应"合成集 mutation_score 0.955 饱和/
变异体太弱"的审稿人质疑：真实基准（ULT）+ 官方变异协议（cosmic-ray）
下生成测试质量仍高（距 gold 仅 7.2pp），但**不能**据此推断
detection 能力强。

**口径标签**（跨报告引用纪律）：
- `max_mutants=10`（确定性截断面，**非** cosmic-ray 全变异体）；
- `timeout=120s`（timeout 计 killed，ULT 官方口径，2026-10-13 裁定）；
- 任务集不同（specir 25 vs replace 46，重叠仅 7）→ 臂级对比受任务
  混合混淆，配对子集 n=7 作**描述性**证据，不作推断检验；
- 与合成集自研 mutation score（0.955 饱和）**不可直接比**
  （算子集/超时/变异体数量均不同，双口径分述纪律）。

## 4. 分层结论 4：M10 解析层误诊的度量分层（§6.10，ADR-0031/0032）

**事实**（ADR-0031 LLM 结构化输出加固 + ADR-0032 M10 可观测性强化）：
- 此前 ~7-8% 任务（6/75）触发 M10 降级，其中**大部分实为解析层缺陷**
  而非 LLM 缺字段：①JSON 语法非法（LLM 写 `10**18` 类 Python 数值
  表达式）→ 叶子回退静默返回错误片段 → 误诊"LLM 未输出
  logic_analysis"；②结构化契约无运行时约束（未用 DeepSeek 官方
  JSON Output）；③finish_reason 截断/资源中断静默；
- ADR-0031 三项加固后冒烟 **M10=0**（修复前 1 例回退默认计划）；
- ADR-0032 补 M10 归因分层：`m10_leaf_fallback=True` 标记
  "提取器叶子回退误诊"（纯观测，分离"LLM 真未输出" vs "解析层缺陷"）。

**论文定位**：EMSE 报告 §6.10 须披露**评测可靠性边界**——2026-10-14
之前批次含 ~7-8% 解析层误诊降级（logic_degraded 统计偏保守），
"逻辑驱动"路径实际覆盖率比历史记录更高；对外引用 M10 率
**必须带"误诊已分层"限定语**（ADR-0032 后新批次可分离计数）。

## 6. M4 预注册：QuixBugs specir 扩样确认性实验

> 预注册件：`docs/study/QUIXBUGS_SPECIR_EXPAND_PREREG_2026-10-14.md`
> （gitignored，本地件，**结果产出前落盘**——EMSE Registered Reports 机制）。

**背景**：QuixBugs specir pilot 阳性趋势 δ=+14.29pp / p=0.125（n=35，
标准口径 6:1），功效不足需补样。temp=0 常驻（R11）⇒ 同任务重跑=
零信息，补样须**换任务子集**（QuixBugs 本地即完整 Python 子集 50
程序，存量 pilot 已用 35/50 → 扩样用剩余 15 + 换 35 任务重新抽样
= 70 任务，4 臂：specir / nl_baseline / specir_repeat / nl_baseline_repeat）。

**判定规则**（与 61a7e04 同族）：合并 McNemar（n≥70 有效配对）
p<0.05 ∧ δ≥8pp = confirmed / p<0.10 ∧ δ>0 = trend / 其余 = not_confirmed。

**成本预算**：~$0.3（70 任务 × 4 臂，QuixBugs 真实代码，temp=0 缓存
命中率高，实际 LLM 调用 < 280 次）。
