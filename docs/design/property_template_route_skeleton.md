## 1. 触发条件（与 prereg E1 判定字面绑定）

| E1 结果（spec_compile_rate，expr 通道） | 动作 |
| --- | --- |
| ≥ 0.3 | 契约修复有效，逻辑驱动主张保留——**本骨架销毁或归档 docs/history/** |
| [0.2, 0.3) | 灰区：恰一次 prompt 契约迭代后重跑一次——本骨架继续待命 |
| < 0.2（或迭代后仍 < 0.3） | 逻辑驱动主张放弃；**本骨架激活为正式预注册草案** |

## 2. 路线定义（LLM 属性模板测试生成）

- **假设草案（H-P1）**：以 Hypothesis 策略为执行后端，LLM 按
  "函数签名 + docstring + 参数类型"产出 `@given` 策略与不变量断言
  （属性测试），其缺陷检出代理指标显著高于 plain prompt 直接生成
  示例测试的基线。
- **与既有资产的关系**：hypothesis==6.168.4 已是项目可选依赖（G18/T5，
  SpecIR→Hypothesis 编译路径已存在）；本路线**复用其策略执行与收缩
  （shrink）能力**，但输入从 SpecIR 规约改为 LLM 直产的属性模板——
  即"逻辑驱动"叙事失效后，同一执行底座改由 LLM 供料。
- **对外表述红线**：本路线激活即意味着"逻辑驱动"主张放弃（prereg E1
  条款字面执行）；对外定位为"LLM 属性模板测试生成"，**不得**复活
  "规约驱动/逻辑锚定"表述（与 AL5 去主张纪律同口径）。

## 3. 设计草图（激活时确认为正式预注册）

- **数据**：synthetic n=87 × seed {42, 44}（与 E2 同池可比）；
- **臂**：{property_template, plain_prompt_tests, gold_tests(参照，不计入
  显著性)}；`AITESTER_PROFILE=logic` 其余档位开关沿用 E2 口径；
- **主终点草案**：buggy 代码上的检出率（属性测试失败 = 检出；gold
  独立裁决沿用 M1）；配对差 property_template − plain_prompt_tests
  （McNemar + 贝叶斯 + BH-FDR，统计计划照抄 prereg 通用节）；
- **次要终点草案**：策略编译率（LLM 产物可被 hypothesis 执行的比例）
  ——本路线对 E1 spec_compile_rate 的同位指标；
- **草案默认阈值（激活时可修订，修订须留痕）**：策略编译率 ≥ 0.5
  视为路线可行；< 0.3 视为路线亦不可行（两次 gate 失败 = 回到纯
  检出优先协议，不迭代第三次）；检出配对差 ≥ +5pp 且 CI 不含 0
  视为属性模板有效；
- **预算草案**：≈ 2M token（两臂 × 87 × 2 种子，thinking 关口径）。

## 4. 前沿依据（激活时引用，均需届时联网复核版本）

- "Can Large Language Models Write Good Property-Based Tests?"（LLM
  产 PBT 实证，两种提示技术）；
- PropertyEval：属性测试用例的 LLM 代码生成基准（GitHub 开源）；
- LLM 单元测试生成综述（arXiv 2025-11）：SOTA 形态 = 经典 SE 原则
  （含属性测试）适配 LLM 管线——本路线即该主张的直接实例化；
- UW 实证（LLM oracle 变异分 43% vs 传统 45%）：LLM 产 oracle 的
  有效性上界与质量风险并存——本路线须以变异检出作有效性裁决
  （ENABLE_MUTATION_SCORING 既有通道）。

## 5. 风险与回退

| 风险 | 缓解 |
| --- | --- |
| LLM 产策略退化（范围过窄 / 恒真属性） | 策略编译率 gate + 变异检出独立裁决；恒真属性由既有 SpecIR v1 编译缺陷修复同型检查拦截 |
